# nfzkbh201.github.io

Personal GitHub Pages portfolio for Noor Zeb Khan.

## Deploy

Create a public GitHub repository named exactly:

```text
nfzkbh201.github.io
```

Then push this folder:

```bash
git init
git add index.html .nojekyll README.md
git commit -m "Launch personal portfolio"
git branch -M main
git remote add origin https://github.com/nfzkbh201/nfzkbh201.github.io.git
git push -u origin main
```

GitHub Pages will publish it at:

```text
https://nfzkbh201.github.io/
```
